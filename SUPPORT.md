# Support

> **Note:** this is [qlcconsole](https://github.com/sandinak/qlcconsole), a
> personal fork of QLC+ — not affiliated with the upstream project. **Fork-specific
> bugs and questions** (Programming tab, group scenes, effect scripts, macOS
> packaging) go to
> [this repo's issues](https://github.com/sandinak/qlcconsole/issues).
> **General QLC+ usage questions** (fixtures, DMX/Art-Net/sACN setup, virtual
> console widgets, anything not specific to this fork) are better served by
> upstream's forum and docs below, since that's where the broader knowledge
> base lives.

Thank you for using qlcconsole! This document will guide you on how to get
help and report issues — for this fork specifically, and for QLC+ in general.

## Where to Get Help

- **qlcconsole (this fork):** [GitHub Issues](https://github.com/sandinak/qlcconsole/issues)
  for anything specific to this fork — Programming tab, Connections/Devices
  tree, control-surface support, macOS packaging, etc.
- **QLC+ (general usage):** [QLC+ Forum](https://www.qlcplus.org/forum/),
  [Official Documentation](https://www.qlcplus.org/docs/), and
  [upstream GitHub Issues](https://github.com/mcallegari/qlcplus/issues) for
  anything not specific to this fork (fixtures, DMX/Art-Net/sACN setup,
  virtual console widgets) — that's where the broader knowledge base lives.
- **Professional Support and Training** (upstream, not this fork):
  [Book a session](https://qlcplus-merch.myshopify.com/products/1h-expert-qlc-consulting-session)

## Before You Ask for Help

Please:

- Search [this fork's issues](https://github.com/sandinak/qlcconsole/issues)
  first if the problem looks fork-specific; otherwise check the
  [QLC+ Forum](https://www.qlcplus.org/forum/) and
  [upstream issues](https://github.com/mcallegari/qlcplus/issues).
- Review the [documentation](https://www.qlcplus.org/docs/) for general QLC+
  answers, or [CLAUDE.md](CLAUDE.md)/[DONE.md](DONE.md)/[TODO.md](TODO.md)
  for this fork's own architecture and development log.
- Make sure you're on the latest qlcconsole build — check
  Help → About for the version string
  (`4.14.2+qlcconsole.<N>`, where `N` tracks this fork's own commit count).

## How to Report Issues Effectively

When reporting a bug, include the following:

- **qlcconsole version:** from Help → About, e.g. `4.14.2+qlcconsole.1197`
- **Operating System:** e.g., Windows 11, Ubuntu 22.04, macOS Ventura
- **Steps to Reproduce:** Clear instructions to trigger the issue
- **Expected Behavior:** What you expected to happen
- **Actual Behavior:** What actually happened
- **Additional Info:** Logs, screenshots, or sample files if relevant

Providing detailed information helps diagnose and fix issues faster.
