# Level 0 — Lighting concepts

Why a show has lighting, what light does, what the audience reads from
it, how a song and a show are lit, and how a show is run — before any
app. Then the virtual stage we light it on.

*Outcome: students can say what light is for in a show choir number, mark
a song's sections and what the audience should feel at each change, use
the crew's words (look, cue, build, button, standby, busking), and find
their way round the virtual stage.*

Lessons 0.1–0.7 need no computers and take 20–30 minutes each, so two
can share a class period. Lesson 0.8 is a full period on the computers.
