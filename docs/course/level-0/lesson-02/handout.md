# Lesson 0.2 — What light does

**Student handout**

## Why this matters

Lesson 0.1 named the jobs light does. To make light do them you need
the controls. Every change you will ever program is a change to one of
four qualities. Name the quality and you can say exactly what you want:
"cooler and dimmer", not "different".

## Today you will

- learn the four qualities of light;
- watch the clip again, only for the lighting, and log each change by
  quality and job.

## Words for today

| Word | Means |
|---|---|
| **Intensity** | How bright a light is, from **Full** (100%) down to **Out** (off). Also called **level**. |
| **Colour** | **Warm** colours (amber, warm white) read friendly and close; **cool** colours (blue, lavender) read calm, cold or night. **Saturated** colours are deep; **pale** ones have white mixed in. |
| **Direction** | Where the light comes from: **front** shows faces, **back** outlines performers, **side** sculpts bodies, **below** looks dramatic or unnatural. |
| **Movement** | Light that changes while you watch: a fade, a chase, beams sweeping across the stage. |
| **Fade / snap** | A change that takes time / a change with no time at all. |

## Light log: only the light

Watch the clip again and watch **only the lighting**. Each time it
changes, log it.

| When (a lyric, or "first chorus") | What changed (which quality?) | Why? (which job, from 0.1?) |
|---|---|---|
| | | |
| | | |
| | | |
| | | |

*Example:* "First chorus: brighter and shifted to pink (intensity,
colour), for the jump in energy (rhythm, mood)."

## Done early?

Our song this year is **"Everybody Scream"**, and the design goes dark
and dramatic. Pick one moment (the opening, a verse, the biggest chorus,
the ending). Which quality would you change there, and which job would
that do?
