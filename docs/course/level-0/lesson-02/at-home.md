clip from a musical; keep it school-appropriate). Log **three** changes:

| When | What changed (which quality?) | Why? (which job?) |

| | | |
| | | |
| | | |

Bring the log, with the name of what you watched.

## B. On paper

or moment it would suit, and why. *Example:* "Colour, cool: a lullaby,
because it reads as night."
