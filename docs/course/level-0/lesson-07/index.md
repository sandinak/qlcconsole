# Lesson 0.7 — Running a show: cues, calls and busking

No computers; cue cards and a song. How a show is run: the cue list, the
stage manager's calls (standby, GO), who does what on the crew, and
**busking**: running light live, by feel, when the show doesn't go to
plan. About 25 minutes; the rest of the period can finish Level 0 check
part 1 or start Lesson 0.8.
