# Lesson 0.1 — What light does

**Student handout**

## Today you will

- watch a show choir number twice: once for the singers, once only for the
  light;
- learn the words a lighting designer uses;
- write down what the light did, and why.

## Words for today

| Word | Means |
|---|---|
| **Intensity** | How bright the light is. *Full* is all the way up; *Out* is off. |
| **Colour** | What colour the light is. **Warm** colours (amber, warm white) feel friendly; **cool** colours (blue, lavender) feel calm, cold or night-time. **Deep** (saturated) colours are strong; **pale** ones are soft. |
| **Direction** | Where the light comes from: the **front** (shows faces), the **back** (outlines the singers), the **side** (shapes bodies), **below** (drama, spooky). |
| **Movement** | Light that changes while you watch: a slow fade, a chase, moving beams. |
| **Cue** | A moment where the light changes. |
| **Focus** | Where the audience looks. The eye goes to the brightest place. |
| **Mood** | What a moment *feels* like. |
| **Energy** | How big the music is: a quiet verse, a huge chorus. |

## The four jobs of light

1. **See** — the audience can see the singers' faces.
2. **Where to look** — the brightest place is where the eye goes.
3. **Mood** — the light tells you how to feel.
4. **Energy** — the light matches the music: small for a verse, big for a
   chorus.
