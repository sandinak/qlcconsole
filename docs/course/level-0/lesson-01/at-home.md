# At home — Lesson 0.1

Do **one** of these. No app needed this week.

## A. Watch a performance (computer, phone or TV)

1. Watch **any** live performance with stage lights: a concert video, a
   music video filmed on a stage, a TV talent show, a musical's clip.
   Pick something school-appropriate.
2. Fill in a **light log** with **three** light changes:

   | When | What changed (which quality?) | Why? (which job?) |
   |---|---|---|
   | | | |
   | | | |
   | | | |

3. Bring the log to class, with the name of what you watched.

## B. On paper (no screen handy)

1. Look at the seven pictures on the [handout](handout.md) (or the printed
   cards).
2. For each, write **one** kind of song or moment it would suit, and why.
   *Example:* "Colour, cool: a lullaby — it feels like night."
3. Bonus: next time you're at a concert, a game, a church service or a
   school event with lights, notice one light change and tell us about it.
