# At home — Lesson 0.1

Do **one** of these. You won't need the app this week.

## A. Watch a performance (computer, phone or TV)

1. Watch a live performance with stage lighting: a concert, a music
   video shot on a stage, a televised talent show or a clip from a
   musical. Keep it school-appropriate.
2. Log **three** lighting changes:

   | When | What changed (which quality?) | Why? (which job?) |
   |---|---|---|
   | | | |
   | | | |
   | | | |

3. Bring the log to class, with the name of what you watched.

## B. On paper (no screen available)

1. Look at the seven pictures on the [handout](handout.md) (or the printed
   cards).
2. For each one, name a song or moment it would suit, and say why.
   *Example:* "Colour, cool: a lullaby, because it reads as night."
3. Bonus: the next time you're somewhere with stage lighting (a concert,
   a game, a service, a school event), note one lighting change and
   bring it to class.
