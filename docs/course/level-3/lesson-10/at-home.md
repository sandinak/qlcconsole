# At home — Lesson 3.10

Do **one** of these.

## A. On your computer (Mac, Windows, or Linux)

1. Install qlcconsole: [Install](../../install.md).
2. Download [`classroom-eos.asc`](../../shows/classroom-eos.asc) (on
   GitHub: open it, then **Download raw file**), and import it into a new
   show as in class.
3. Add a cue between **3 House out** and **4 Opening** for a slow cyc
   build before the first song. What number does it get, and why?
4. Save it as `Lesson3-10-Home-yourname.qlcc` and bring it (USB stick or
   the class folder), or hand in a screenshot of the cue list.

## B. On paper (no computer, or a Chromebook without Linux)

1. Finish the translation table from Part 1 of the handout.
2. Add three Eos ideas you use that aren't in it, and write where you
   think each would live in qlcconsole. Bring it to class to check.
