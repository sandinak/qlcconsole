## 1. Show control and timecode

- Title, Level 3 · Lesson 5
- *Say:* "The sound op and the lights have to land together."

## 2. Three ways to start a cue

- A hand on GO.
- A number: QLab fires "GO 1.0.2".
- A clock: both computers follow the same timecode.

## 3. What a number promises

- Renumber the cues and QLab fires the wrong ones.
- A number is an address the sound op has written down.

## 4. Follow timecode

- On the list; a time on each cue; Run tab shows the **at**.
- A cue with no time is left to GO.

## 5. One GO

- Key, Run tab, pad, phone, QLab, clock: the same GO.
- The phone page has its own switch and PIN.
