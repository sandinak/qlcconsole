## 2. The note

- *"Less pink."* An hour before curtain.
- *Ask:* "Where is the pink? How many cues, how many layers?"

## 3. A palette is a name for a value

- Every cue that uses it shows its value.
- Change the palette: every cue follows.

## 4. Who uses it?

- Library → right-click → **Used by**.
- Check it before you change a palette.

## 5. The song's own colours

- Don't change the show's Magenta: other songs may use it.
- **Duplicate**, name it, file it in the song's folder.
- Pictures: `duplicate.png`, `song-folder.png`.

## 6. Name it for its job

- *Chorus Colour*, not *Chorus Pink*: the value will change, the job
  won't.

## 7. Use it

  own).
