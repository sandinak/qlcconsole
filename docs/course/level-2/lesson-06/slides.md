## 2. When you busk

- A vamp, a soloist who goes long, an encore, a problem on stage
  (Lesson 0.7).
- The cue list can't know; the op has to.

## 3. A hit

- A state fired by hand, not a cue in the list.
- Built like a cue: layers, colours, levels, aims.
- It never tracks: it plays only what it has.

## 4. The Hits section

- Right-click the production → **+ Hit**; name it.
- Picture: `hits.png`.

## 5. A button each

- **Make VC page**: a frame on the Virtual Console, a button per hit.
- Toggle: on, then off.

## 6. Over the running list

- The verse keeps running; the hit plays on top. Let go: the verse is
  back.
- Picture: `rig-verse-stab.png`.
