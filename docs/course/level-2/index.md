# Level 2 — Intermediate

Programming a whole song the way a professional does: tracking, palettes,
parts of a group, effects, moving lights on lines, busking hits and
sub-cues.

*Outcome: students program a whole song the way a pro does: with
tracking, reusable palettes, effects on the pixel fixtures, moving lights
on lines, and busking hits for the unexpected.*

Each lesson starts from the one before's finish file (2.1 from Lesson
1.4's), and opens with the Level 0 idea it applies.
