## Download

Open the [qlcconsole Releases page](https://github.com/sandinak/qlcconsole/releases)
and take the newest release numbered **0.3.0 or higher** (a *Pre-release*
is fine). Under **Assets**, pick your file:

| Computer | File |
|---|---|
| Mac (macOS 12+) | `qlcconsole-…-universal-….dmg` |
| Windows 10/11 (64-bit) | `qlcconsole-…-win64-setup.exe` |
| Linux (64-bit Intel/AMD) | `qlcconsole-…-x86_64.AppImage` |

## Install

- **Mac:** open the `.dmg`, drag **qlcconsole** into **Applications**,
  open it from there.
- **Windows:** run the setup file. If Windows says *"Windows protected
  your PC"*, click **More info → Run anyway**. A school laptop that
  blocks installs: ask your teacher.
- **Linux:** make the file runnable (right-click → Properties → *Allow
  executing*, or `chmod +x qlcconsole-*.AppImage`), then double-click it.
- **Chromebook:** only with the Linux development environment on *and*
  an Intel or AMD chip; then follow the Linux steps in **Linux files**.
  Otherwise use the practice version your lesson page links, or the paper
  option of the at-home task.

## Your shows

- Make one folder for the course: **Documents → qlcconsole** (Chromebook:
  **Linux files → qlcconsole**).
- Open a lesson's show with **File → Open**. Save your own work with
  **File → Save As** under a new name, like `Lesson01-yourname.qlcc`.
- To bring a show to class: USB stick, the school's cloud drive, or email
  it to yourself.

The course shows aren't connected to real lights, so the footer reads
**No outputs: preview only**. That's expected.
