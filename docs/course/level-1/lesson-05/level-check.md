# Level 1 check — light a 30-second clip

*One or two class periods after Lesson 1.5. Groups of 2–3.*

## The task

Light **30 seconds** of a song and run it live while it plays.

1. **Pick the clip.** The teacher gives one (a different part of
   "Everybody Scream", or another song), or groups choose one the teacher
   approves.
2. **Design it on paper.** A cue sheet with **3 to 5 cues**:

   | Cue | When (words or time) | What should the audience feel? | Lights (group: colour, level, aim) | Time (snap / fade / hold) |
   |---|---|---|---|---|
   | 1.0.0 | | | | |
   | | | | | |

3. **Build it** in qlcconsole, from
   [`lesson-1-1-start.qlcc`](../../shows/lesson-1-1-start.qlcc) (the
   empty classroom show): **+ Production** (your group's name), **+ Cue
   list**, your cues, their layers, looks and times. Save it as
   `Level1-check-group.qlcc`.
4. **Run it live** for the class: one student calls (SM), one runs the
   board, while the clip plays. Then a **one-minute talk**: what you
   wanted the audience to feel, and how the light did it.

Everything needed is in Lessons 1.1–1.5: groups, colours and levels
(1.1), changing looks and cue looks (1.2), front light and aims (1.3),
timing (1.4), calling and running (1.5).

## Rubric

| | Beginning (1) | Developing (2) | Proficient (3) | Advanced (4) |
|---|---|---|---|---|
| **Design** (the cue sheet) | Cues with no reasons | Some cues have a reason | Every cue has a reason that fits the music | Clear contrast and a story across the cues; colour, level, direction and timing all chosen on purpose |
| **Programming** (the cue list) | Fewer than 3 cues, or it doesn't play | Plays, but differs from the sheet | Plays what the sheet says | Plays what the sheet says, with faces lit and moving lights aimed |
| **Operation** (the live run) | Cues missed or very late | Some cues early or late | Every cue on its call | Clean calls and GOs; a mistake recovered calmly (Back, LOAD) |
| **Teamwork** (and the talk) | One person did it | Roles shared unevenly | Everyone had a role | Everyone can explain every cue |

**Pass:** 3 or more in every row. Below that: what to practise, then run
it again.
