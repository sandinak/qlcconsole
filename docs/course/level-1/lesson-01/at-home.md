# At home — Lesson 1.1

Do **one** of these.

## A. On your computer (Mac, Windows, or Linux)

1. Install qlcconsole: [Install](../../install.md).
2. Download [`lesson-01-start.qlcc`](../../shows/lesson-01-start.qlcc)
   (on GitHub: open it, then **Download raw file**).
3. Build the three cues again **without looking at the handout pictures**:
   Pose, Verse, Chorus. Use the handout's steps if you get stuck.
4. Now make it **yours**: change the colours to tell a different story
   (a sad song? a spooky one?). Change at least one colour in each cue.
5. Make the production current and play it in the **Run** tab.
6. Save it as `Lesson01-Home-yourname.qlcc` and bring it (USB stick or the
   class folder), or hand in a screenshot of each cue in the Rig Overview.

Nothing you do can harm real lights: the course show isn't connected to
any.

## B. On paper (no computer, or a Chromebook without Linux)

1. Pick a song you like (school-appropriate). Listen to the first minute.
2. Fill in a cue sheet with **three to five cues**:

   | Cue | When (words or time) | What should the audience feel? | Lights (group: colour, level) |
   |---|---|---|---|
   | 1.0.0 | | | |
   | 1.0.1 | | | |
   | 1.0.2 | | | |

   Use our groups: Risers, Riser Tops, Cyc Washes, Pixel Boxes, Front Wash,
   Movers, Back Beams, Lanterns. Use our colours: White, Warm White, Red,
   Amber, Yellow, Green, Cyan, Blue, Lavender, Magenta. Levels: Full, 75%,
   Half, 25%, 10%, Out.
3. Next class, a partner builds your cue sheet in the Show Tree and you
   check it matches your design.
