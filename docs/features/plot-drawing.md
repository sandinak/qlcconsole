# Printing the plot

A light plot on paper or as a PDF, made from the Lighting Studio's plot: a
drawing for the crew to hang and focus from, for the venue's technical
director, or to pin up at the tech table.

Open it from the Lighting Studio toolbar's **More ▸ Print & Reports ▸ Print
Plot / Save PDF…**. The same submenu has the **Patch List…** and the
**Network Report…**, the show's other paperwork.

## What is on the sheet

One landscape page:

- **The drawing**: the plot as the Studio draws it (the same symbols,
  labels and colours, on the plot's own background), framed with the stage
  directions round the edge. Anything placed just off the stage grid, a FOH
  truss or a boom in the wings, is in the frame too.
- **A scale bar** under the drawing, a round length in the unit chosen in
  **Settings ▸ Units**: whole feet (feet and inches is the default), or
  metres in 1-2-5 steps. The plot is drawn to fit the page, so measure with
  the bar, not a ruler's markings.
- **Symbol key**: one row for each kind of fixture on the plot (its
  definition, and the plot symbol it is drawn with), with its symbol as the
  plot draws it and how many there are, most first, and the total. A row
  says "drawn by kind" when the fixture's Plot symbol is Auto.
- **Layers and owners**: how many fixtures are on each plot layer and how
  many belong to the tour, the house and rentals (see
  [Owner: Tour, House or Rental](venues.md#owner-tour-house-or-rental)). When the plot shows the **Owner**
  overlay, each owner has its colour square.
- **Title block**, bottom right: the title, venue, who drew it, the date,
  the revision, the view, the scale and the paper.

A fixture on a hidden plot layer is not drawn and not counted; the sheet
lists how many were left off, and the dialog says so too. Show the layer
in **Plot layers** to print it.

## The dialog

- **Title** starts as the show's file name; **Venue** as the venue the show
  is set to, if any. **Drawn by** is remembered for the next sheet.
  **Revision** is free text (A, B, or 2, 3).
- **View**: **Plan (top)**, **Front elevation**, **Side elevation**, or
  **Rig Overview (angled)**. The angled look is a picture of the Rig
  Overview from where its camera is (open the Rig Overview first and turn
  it to the angle you want); it is not to scale, so it has no scale bar.
- **Paper**: Letter, Legal, Tabloid, A4 or A3. Letter is the first choice
  when Settings ▸ Units is in feet or inches, A4 when it is metric.
- **Show**: tick off the symbol key, or the layer and owner key, for a
  bigger drawing area.

The preview on the right is the page as it prints. **Save PDF…** asks
where to save it (the name offered is the show's, plus the view);
**Print…** opens the computer's print dialog. Printing or saving never
changes the show or the Studio: the Studio stays in the view it was in.

## Tips

- Turn on **Fixture Labels** in the **Show** menu on the Studio's footer first if the crew needs
  the names on the drawing; the plot prints what it shows.
- For a page per position, put each position's fixtures on its own plot
  layer and hide the others before printing.
- The patch itself (addresses, modes, circuits) is the
  [patch list](fixture-manager.md#the-patch-list), which prints and saves as a PDF too.
