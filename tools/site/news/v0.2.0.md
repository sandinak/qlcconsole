title: "The Show Tree arrives: 0.2.0 beta"
---
The first Show Tree release. A whole show is written as one tree
(productions → cue lists → cues → layers → looks), with tracking like a
theatre console.

**Highlights**

- **The Show Tree,** with sub-cues and a cue runner for playback.
- **Focus mode** and **line targets** for aiming moving lights at places
  rather than at pan and tilt values.
- **Curtains that move,** colour rings on movers, and Matrix effects for
  pixel boxes.
- **Safe on the venue network:** output goes only to the rig network.
- **Software updates** that install at quit, never during a show.
