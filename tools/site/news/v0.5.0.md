The first public release since 0.4.3. It brings together ten rounds of work
tested on our own rigs, aimed at running a real show from a game controller
and patching it with confidence.

**Highlights**

- **Run the show from a game controller:** two controls to arm, LT as the
  safety for GO and Back, RT for the armed hit, and all four as an emergency
  stop that puts every light at rest from any pad, the phone, OSC or MSC.
- **The DMX map in Connections** shows what each block is, with a legend,
  hover detail and a Test mode to bring channels up by hand; the Patch List
  prints per universe and addresses read U3.001.
- **Fire Spread** catches across the stage from one point, in two colours,
  over what is already lit.
- **Choose your tabs** for each show, and shorter right-click menus in the
  order you work.
- **Lasers, foggers and flame relays held for the show:** the *Show only*
  output rule keeps them off until a cue runs them in Operate.

On Windows, game-controller control is turned off for now except the
emergency stop, which still works there.
